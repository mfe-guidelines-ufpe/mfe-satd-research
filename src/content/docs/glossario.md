---
title: Glossário
description: Termos e siglas usados na pesquisa.
---

| Termo | Significado |
|---|---|
| **MFE** | Microfrontend: parte independente de um frontend maior, que pode ser desenvolvida e implantada separadamente. |
| **SATD** | *Self-Admitted Technical Debt*: dívida técnica que o próprio desenvolvedor reconhece no código, em comentários ou mensagens de commit. |
| **DTS1** | Dataset de mapeamento do ecossistema open source de microfrontends. |
| **DTS2** | Dataset de SATD extraída dos repositórios do DTS1. |
| **MSR** | *Mining Software Repositories*: área de pesquisa que analisa dados de repositórios de software. |
| **Adjudicador** | Analista que dá o veredito quando analista e revisor divergem. |
| **Falso positivo** | Registro capturado pelo minerador que não é, de fato, dívida técnica. |
