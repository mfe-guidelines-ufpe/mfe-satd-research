## Base

A taxonomia parte de Maldonado & Shihab (2015).

## Dimensões de localização em microfrontends

A base foi estendida com dimensões que dizem **onde** a dívida está na arquitetura:

| Dimensão | Onde a dívida está |
|---|---|
| Intra-MFE | Dentro de um único microfrontend |
| Integration Debt | Na integração entre microfrontends |
| Contract Debt | Nos contratos entre microfrontends |
| Isolation Debt | No isolamento entre microfrontends |

## Categorias propostas

Categorias próprias desta pesquisa, específicas de microfrontends:

- Dívida de Interface Alotrópica
- Dívida de Contexto Transitório
- Síndrome da Rejeição de Orquestração
